This project is a website designed as an interactive digital memory book.
The website is protected by a special password and opens into a collection of memories, photographs, messages, hidden easter eggs, and music.
The visual theme is inspired by lily flowers, botanical journals, old paper textures, and handcrafted scrapbooks.

Features

 Lock Screen

* Password-protected entry
* Floating lily petals
* Unlock animation
* Custom transition into the main website

 Home Page

* Welcome message
* Hero photograph
* Animated background elements

 Memory Timeline

* Interactive timeline of important memories
* Lily-themed navigation

 Photo Gallery

* Polaroid-style photo frames
* Captions and notes
* Full-screen image viewing

 Letters

* Hidden letters and messages
* Interactive envelopes

 Music Player

* Floating music controls
* Playlist integration
* Background listening experience

 Easter Eggs

* Hidden clickable flowers
* Secret messages
* Unlockable surprises



 Design Goals

* Warm and personal
* Handcrafted appearance
* Calm and elegant animations
* Mobile-friendly
* Story-driven experience
